# Sistema de Cadastro de Alunos (Atividade 2)

Aplicação web desenvolvida em Java com Spring Boot e Thymeleaf para o gerenciamento de alunos (CRUD completo). Este projeto foi desenvolvido como parte das atividades práticas de programação web.

## 🚀 Tecnologias Utilizadas

- **Java**
- **Spring Boot** (Web, Validation)
- **Thymeleaf** (Template Engine)
- **Gradle** (Gerenciador de dependências)
- **Jakarta Bean Validation** (Validação de formulários)
- **HTML5 & CSS3** (Interface visual)

## ⚙️ Como Executar

### Pré-requisitos
- Java instalado na sua máquina.
- Não é necessário ter o Gradle instalado globalmente, o projeto utiliza o Gradle Wrapper incluído.

### Executando a Aplicação
Abra o terminal na pasta raiz do projeto e execute o comando abaixo:

```bash
# No Windows:
gradlew bootRun

# No Linux/Mac:
./gradlew bootRun
